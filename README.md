
# AI Engineering Operations Assistant

An AI-powered assistant designed to help software engineering teams
search engineering knowledge, troubleshoot operational issues,
analyse incidents, and improve engineering productivity.

## Problem Statement

Engineering knowledge is often scattered across architecture documents,
runbooks, incident reports, release notes, and troubleshooting guides.

Finding the right information during incidents or operational
investigations can be time-consuming.

This project explores how AI, Retrieval-Augmented Generation (RAG),
and knowledge retrieval can make engineering knowledge easier to access
and act upon.

## Goals

- Search engineering documentation using natural language
- Generate answers grounded in source documents
- Cite source documents used to generate answers
- Summarise incident reports
- Identify possible root causes and follow-up actions
- Explore practical AI-assisted engineering workflows

## Planned Architecture

- Python
- FastAPI
- Streamlit
- Large Language Model (LLM)
- Retrieval-Augmented Generation (RAG)
- Vector database
- AWS deployment
